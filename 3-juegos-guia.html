Cómo está organizada esta guía

Cada uno de los 3 juegos sigue la misma estructura: primero se explican, en un lenguaje sencillo, los conceptos de JavaScript que ese juego necesita; después se construye el HTML, luego el CSS y por último el JavaScript, mostrando el código completo de cada archivo (nada se deja fuera ni se resume con puntos suspensivos). Entre paso y paso encontrarás un checkpoint visual: una imagen que muestra cómo debe verse tu juego en ese punto, para que compares tu resultado.

El código de esta guía está bloqueado para copiar y pegar a propósito. Transcríbelo a mano en tu propio editor: escribir cada línea te obliga a leerla con atención.
No hay ningún entorno para ejecutar código dentro de esta guía. Debes crear los archivos index.html, style.css y script.js en tu computador y abrirlos en tu navegador para probarlos.
Los "checkpoints" son imágenes (dibujadas en SVG) que muestran el aspecto y el contenido esperado de tu juego en un momento dado, no el código ni una demostración interactiva.
Juego 1

Adivina el número

La computadora elige en secreto un número entre 1 y 100. El jugador escribe números hasta acertar, y el juego le dice si su intento fue muy alto o muy bajo.

Conceptos que necesitas

Math.random()

Devuelve un número decimal aleatorio entre 0 (incluido) y 1 (no incluido). Es la base para generar cualquier valor al azar en JavaScript.

Math.floor()

Redondea un número decimal hacia abajo, quitando la parte decimal. Combinado con Math.random(), sirve para obtener números enteros aleatorios dentro de un rango.

Number() e isNaN()

Number(texto) convierte un texto en un número. isNaN(valor) comprueba si ese resultado no es un número válido, útil para validar lo que escribe el usuario.

Comparación de números

Los operadores ===, > y < permiten comparar el número del usuario contra el número secreto para decidir qué mensaje mostrar.

addEventListener("click")

Ejecuta una función cada vez que el usuario hace clic en un botón, como el botón de "Adivinar" o el de "Reiniciar".

textContent

Permite leer o cambiar el texto visible de un elemento, que usaremos para mostrar los mensajes de "muy alto", "muy bajo" o "correcto".

Paso 1: estructura HTML

Necesitamos un campo para que el usuario escriba su número, un botón para confirmar el intento, un lugar para mostrar mensajes, un contador de intentos y un botón para volver a jugar.

El <input type="number"> restringe (de forma suave, el usuario aún puede escribir otra cosa) el campo a valores numéricos, y los atributos min y max documentan el rango esperado. Cada elemento tiene su propio id porque así los vamos a encontrar por separado desde JavaScript.

Checkpoint visual 1 de 3

Así debe verse la página apenas cargas el HTML (todavía sin estilos ni lógica): el título, el campo, el botón, el contador en cero y el botón de reinicio.

Paso 2: estilos CSS

El CSS no cambia el comportamiento del juego, solo su apariencia: le da una tarjeta con bordes redondeados, espacio interno, y estilos a los campos y botones.

La clase .juego es el contenedor principal. button:disabled define cómo se ve el botón "Adivinar" cuando lo desactivemos al ganar la partida, para que quede visualmente claro que ya no se puede seguir jugando.

Paso 3: lógica en JavaScript

Aquí vive el comportamiento real del juego: generar el número secreto, leer el intento del usuario, compararlo, y actualizar los mensajes en pantalla.

Las primeras dos líneas crean el estado del juego: numeroSecreto (usando Math.floor(Math.random() * 100) + 1, que genera un entero entre 1 y 100) y intentos, que empieza en 0. Ambas están declaradas con let porque sus valores cambiarán mientras se juega.

Las siguientes cinco líneas guardan en variables cada elemento del HTML que vamos a necesitar, usando document.getElementById.

Dentro del addEventListener("click") del botón "Adivinar": primero convertimos el texto del input a número con Number(input.value). La condición if (input.value === "" || isNaN(numeroUsuario)) comprueba dos casos de error: que el campo esté vacío, o que lo escrito no sea un número (por ejemplo, letras); en ambos casos mostramos un mensaje y salimos de la función con return, sin sumar un intento.

Si el número es válido, aumentamos intentos en 1 y actualizamos el contador en pantalla. Luego, la cadena de if / else if / else compara numeroUsuario contra numeroSecreto: si son iguales, mostramos el mensaje de victoria y desactivamos el botón con btnAdivinar.disabled = true; si el intento es mayor, avisamos que baje; si es menor, avisamos que suba. Al final, input.value = "" limpia el campo para el siguiente intento.

El botón "Reiniciar juego" vuelve a generar un número secreto, pone los intentos en 0, limpia el mensaje, reactiva el botón "Adivinar" (disabled = false) y limpia el campo de texto, dejando el juego exactamente como al principio.

Después de un primer intento incorrecto: aparece el mensaje de pista y el contador de intentos sube a 1.

Checkpoint visual 3 de 3

Al acertar: el mensaje de victoria incluye el número secreto y la cantidad de intentos, y el botón "Adivinar" se ve deshabilitado (gris).

Juego 2

Piedra, papel o tijera

El jugador elige una opción haciendo clic en un botón; la computadora elige al azar entre las mismas tres opciones, y el juego determina quién ganó según las reglas clásicas.

Conceptos que necesitas

Arrays

Una lista ordenada de valores, como ["piedra", "papel", "tijera"]. Nos sirve para guardar las tres opciones posibles y para que la computadora elija una al azar entre ellas.

Índice aleatorio de un array

Combinando Math.floor(Math.random() * array.length) obtenemos una posición válida al azar dentro del array, y con array[posición] accedemos a ese valor.

querySelectorAll + forEach

Selecciona todos los botones de opción a la vez y permite agregarle su propio evento de clic a cada uno, recorriendo la lista.

dataset

Cada botón guarda su opción en un atributo data-opcion. Desde JavaScript, boton.dataset.opcion nos dice qué eligió el jugador.

Operadores lógicos && y ||

&& (y) exige que dos condiciones sean ciertas a la vez; || (o) alcanza con que una de varias lo sea. Los usamos para expresar las reglas de quién le gana a quién.

SVG embebido en HTML

En vez de usar imágenes o emoticones, dibujamos figuras simples directamente en el HTML con etiquetas <svg>, <circle>, <rect> y <line>.

Paso 1: estructura HTML

Necesitamos tres botones (uno por opción, cada uno con su propio ícono dibujado en SVG y su atributo data-opcion), un lugar para el resultado, un marcador de puntaje y un botón para reiniciar el marcador.

Cada botón contiene un <svg> distinto: un círculo gris para "Piedra", un rectángulo azul para "Papel", y dos líneas cruzadas con dos círculos pequeños (simulando las argollas de una tijera) para "Tijera". El atributo data-opcion es el que JavaScript va a leer para saber qué botón se presionó.

Checkpoint visual 1 de 2

Estado inicial: tres botones con su ícono y su etiqueta, marcador en cero para las tres categorías.

Paso 2: estilos CSS

Solo necesitamos organizar los tres botones en fila y darles una apariencia de tarjeta seleccionable.

display: flex en .opciones coloca los tres botones uno al lado del otro. Dentro de cada botón, flex-direction: column apila el ícono SVG encima del texto.

Paso 3: lógica en JavaScript

Aquí se decide qué elige la computadora y quién gana la partida.

El array opciones guarda las tres jugadas posibles. Las variables ganadas, perdidas y empatadas forman el marcador, inicializado en 0.

document.querySelectorAll(".btnOpcion") selecciona los tres botones a la vez. El forEach les agrega, a cada uno, su propio addEventListener("click").

Dentro del clic: boton.dataset.opcion obtiene la elección del jugador (el botón sobre el que se hizo clic). Para la computadora, generamos un índice aleatorio válido del array con Math.floor(Math.random() * opciones.length) y lo usamos para leer opciones[indiceAleatorio].

La cadena de if / else if / else compara ambas elecciones: si son iguales, es empate. Si no, comprobamos las tres combinaciones en las que gana el jugador (piedra vence a tijera, papel vence a piedra, tijera vence a papel) usando && para combinar ambas condiciones de cada combinación, y || para aceptar cualquiera de las tres. Si ninguna de esas combinaciones se cumple, por descarte, gana la computadora.

Al final del clic actualizamos tanto el texto de resultado como el de marcador, reconstruyendo la cadena de texto completa cada vez a partir de las variables actuales.

El botón "Reiniciar marcador" simplemente vuelve las tres variables de puntaje a 0 y limpia los textos, sin tocar nada más del juego.

Checkpoint visual 2 de 2

Después de elegir "Piedra" y ganarle a la tijera de la computadora: mensaje de resultado y marcador actualizados.

Juego 3

Busca la pareja

Un tablero de cartas boca abajo esconde figuras repetidas en parejas. El jugador voltea dos cartas por turno: si coinciden, quedan reveladas; si no, vuelven a voltearse boca abajo.

Conceptos que necesitas

Arrays y concat()

array.concat(array) une dos arrays en uno solo. Lo usamos para duplicar la lista de símbolos y así crear las parejas de cartas.

Mezclar un array (Fisher-Yates)

Un algoritmo clásico que recorre el array de atrás hacia adelante, intercambiando cada elemento con uno elegido al azar, para desordenar el mazo de forma justa.

createElement anidado

Cada carta se construye con varios elementos creados por separado (la carta, su interior, su cara frontal y su cara trasera) que luego se unen con appendChild.

Flip con CSS (rotateY)

El efecto de "voltear" la carta se logra con transform: rotateY(180deg) y backface-visibility: hidden, sin necesitar ninguna librería.

Delegación de eventos

Un único addEventListener en el tablero completo maneja los clics de todas las cartas, incluso aunque se hayan creado dinámicamente con JavaScript.

setTimeout()

Ejecuta una función después de cierto tiempo (en milisegundos). Lo usamos para esperar un momento antes de volver a ocultar dos cartas que no coincidieron.

Una variable "bloqueado"

Una bandera booleana que evita que el jugador voltee una tercera carta mientras el juego todavía está mostrando el resultado de las dos anteriores.

Paso 1: estructura HTML

A diferencia de los juegos anteriores, las cartas no se escriben a mano en el HTML: solo preparamos un contenedor vacío (el tablero), y JavaScript construye las 8 cartas dentro de él.

El <span id="movimientosJuego3"> dentro del párrafo nos permite actualizar solamente el número de movimientos sin reescribir el resto de la frase. El <div id="tableroJuego3"> empieza vacío; su contenido lo genera por completo el JavaScript del Paso 3.

Checkpoint visual 1 de 3

Tablero recién generado: las 8 cartas están boca abajo, todas con el mismo dorso (un círculo blanco sobre fondo morado).

Paso 2: estilos CSS

El CSS define el tamaño del tablero en cuadrícula y, sobre todo, el efecto de volteo de las cartas en 3D.

perspective en .carta le da profundidad a la animación 3D. .carta-interior es el elemento que realmente rota; sus dos caras (.carta-frente y .carta-reverso) están superpuestas con position: absolute, y backface-visibility: hidden hace que cada cara solo se vea cuando está mirando hacia el usuario. La clase .volteada es la que activa la rotación, y .emparejada cambia el color de fondo de la cara trasera cuando la pareja ya fue encontrada.

Paso 3: lógica en JavaScript

Esta es la parte más larga de la guía: genera el mazo, construye las cartas, controla los volteos y detecta parejas y victoria.

simbolos guarda los 4 nombres de figura que vamos a usar. La función mezclar implementa el algoritmo de Fisher-Yates: recorre el array desde el final hacia el principio con un for, y en cada vuelta intercambia la posición actual (i) con una posición aleatoria entre 0 e i (calculada con Math.floor(Math.random() * (i + 1))), usando una variable temporal para no perder ningún valor durante el intercambio.

let mazo = mezclar(simbolos.concat(simbolos)) duplica los 4 símbolos (obteniendo 8 elementos) y los mezcla; es let porque se va a volver a generar cada vez que se reinicia el juego.

Después de seleccionar los elementos del HTML, declaramos el estado del juego: cartasVolteadas (un array vacío que va a contener, como máximo, las dos cartas boca arriba en un momento dado), bloqueado (empieza en false), movimientos y paresEncontrados, ambos en 0.

crearSvgSimbolo(simbolo) es una función que, según el texto recibido, devuelve el código SVG correspondiente: un círculo azul, un cuadrado verde, un triángulo naranja (usando <polygon> con tres puntos) o una estrella roja (un <polygon> con diez puntos). Usa varios if seguidos, cada uno con su propio return, en vez de if/else if, porque cada return ya corta la ejecución de la función.

crearTablero() primero vacía el contenedor con tablero.innerHTML = "" y luego recorre mazo con forEach. Por cada símbolo crea cuatro elementos anidados: carta (el contenedor exterior, con la clase "carta" y el símbolo guardado en carta.dataset.simbolo para poder compararlo después), interior (el que rota), frente (la cara que se ve boca abajo, con un ícono genérico) y reverso (la cara que muestra el símbolo real, generado con crearSvgSimbolo). Al final los va uniendo con appendChild: primero mete frente y reverso dentro de interior, luego interior dentro de carta, y por último carta dentro del tablero.

El addEventListener("click") está puesto directamente en tablero (delegación de eventos), no en cada carta. evento.target.closest(".carta") encuentra la carta más cercana al punto exacto donde se hizo clic. Las cuatro comprobaciones con return descartan los clics inválidos, en orden: que no se haya hecho clic sobre ninguna carta, que el juego esté bloqueado esperando a que se oculten dos cartas, que esa carta ya esté volteada, o que ya esté emparejada.

Si el clic es válido, se agrega la clase "volteada" a la carta y se guarda en el array cartasVolteadas con push. Cuando ese array llega a tener 2 cartas, se suma un movimiento y se llama a compararCartas().

Dentro de compararCartas(): si el dataset.simbolo de ambas cartas coincide, se les agrega la clase "emparejada" a las dos, se vacía cartasVolteadas y se suma un par encontrado; si paresEncontrados llega a ser igual a la cantidad de símbolos distintos, se muestra el mensaje de victoria. Si no coinciden, se activa bloqueado = true y, con setTimeout, después de 900 milisegundos se les quita la clase "volteada" a ambas cartas, se vacía el array y se libera el bloqueo, dejando el tablero listo para el siguiente turno.

El botón de reinicio genera un mazo mezclado nuevo, pone en cero movimientos y paresEncontrados, vacía cartasVolteadas, quita el bloqueo, limpia los textos y vuelve a llamar a crearTablero() para reconstruir las cartas desde cero.

Checkpoint visual 2 de 3

Segundo turno: se voltearon un círculo y un cuadrado, no coinciden. El contador ya marca 1 movimiento; un instante después, ambas cartas volverán a quedar boca abajo.

Checkpoint visual 3 de 3

Partida terminada: las 8 cartas quedan boca arriba con fondo verde (clase "emparejada") y aparece el mensaje final con el total de movimientos.

Para seguir practicando

Una vez que tengas los 3 juegos funcionando, prueba modificarlos por tu cuenta: cambia el rango de números del Juego 1, agrega una cuarta opción al Juego 2 (por ejemplo "lagarto" y "Spock"), o aumenta el Juego 3 a 6 parejas en vez de 4. Cambiar código que ya entiendes es una de las mejores formas de terminar de dominarlo.
