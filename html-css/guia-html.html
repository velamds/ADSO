● Guía práctica — HTML5

Aprende HTML escribiéndolo, no solo leyéndolo.

Cada sección trae la teoría justa y un laboratorio en vivo: editas el código a la izquierda y ves el resultado a la derecha, al instante. Empieza por la sección 1 y no te saltes los ejercicios.

<html> <body> <div> <a href> <form> <section>
01 · <html>

¿Qué es HTML y cómo se estructura un documento?

HTML (HyperText Markup Language) no es un lenguaje de programación: es un lenguaje de marcado. Describe la estructura y el significado de una página usando etiquetas (tags), casi siempre en pares de apertura y cierre: <p>texto</p>.

  • Una etiqueta puede tener atributos, que le dan información extra: <a href="...">.
  • Todo documento HTML válido empieza con <!DOCTYPE html>, seguido de <html>, <head> y <body>.
  • El <head> guarda metadatos (título, charset, enlaces a CSS); el <body> guarda lo que se ve.
<!-- estructura mínima de una página -->
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
  </body>
</html>

02 · <h1>–<p>

Etiquetas de texto

El contenido textual se organiza con encabezados y párrafos:

  • <h1> a <h6>: títulos, de mayor a menor importancia. Usa un solo <h1> por página.
  • <p>: párrafos de texto.
  • <strong> da importancia (negrita semántica); <em> da énfasis (cursiva semántica).
  • <br> hace un salto de línea; <hr> dibuja una línea divisoria.
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Este es un párrafo con una palabra <strong>importante</strong> y otra con <em>énfasis</em>.</p>
2 Laboratorio: jerarquía de texto

Crea un <h1> con "Mi receta favorita", un <h2> con "Ingredientes" y un párrafo donde una palabra esté en <strong>.

Ver solución sugerida

  <h1>Mi receta favorita</h1>
  <h2>Ingredientes</h2>
  <p>Necesitas <strong>2 tazas</strong> de harina.</p>
</body>
03 · <a> <img>

Enlaces e imágenes

Los enlaces conectan páginas; las imágenes las ilustran. Ambos son elementos con atributos clave:

  • <a href="url">texto</a>: crea un enlace. target="_blank" lo abre en pestaña nueva.
  • <img src="url" alt="descripción">: es una etiqueta "vacía" (sin cierre). alt es obligatorio para accesibilidad.
<a href="https://developer.mozilla.org" target="_blank">Visita MDN</a>

<img src="gato.jpg" alt="Gato naranja durmiendo" >
3 Laboratorio: enlace con imagen

Agrega un enlace a "https://www.wikipedia.org" con el texto "Ir a Wikipedia", y debajo una imagen usando esta URL de prueba: https://picsum.photos/300/150, con un alt descriptivo.

Ver solución sugerida
<body>
  <a href="https://www.wikipedia.org">Ir a Wikipedia</a>
  <br>
  <img src="https://picsum.photos/300/150" alt="Imagen aleatoria de paisaje">
</body>
04 · <ul> <ol>

Listas

HTML tiene tres tipos de listas:

  • <ul>: lista sin orden (viñetas), con elementos <li>.
  • <ol>: lista ordenada (numerada), también con <li>.
  • <dl>: lista de definiciones, con <dt> (término) y <dd> (definición).
<ul>
  <li>Manzana</li>
  <li>Pera</li>
</ul>

<ol>
  <li>Precalentar el horno</li>
  <li>Mezclar ingredientes</li>
</ol>
4 Laboratorio: tu lista de tareas

Crea una lista ordenada con 3 pasos para preparar un café, y debajo una lista sin orden con 3 ingredientes.

Ver solución sugerida
<body>
  <ol>
    <li>Hervir agua</li>
    <li>Añadir café molido</li>
    <li>Servir en la taza</li>
  </ol>
  <ul>
    <li>Agua</li>
    <li>Café molido</li>
    <li>Azúcar</li>
  </ul>
</body>
05 · <table>

Tablas

Las tablas muestran datos en filas y columnas. Se construyen combinando estas etiquetas:

  • <table>: contenedor de la tabla.
  • <tr>: fila (table row).
  • <th>: celda de encabezado; <td>: celda de datos.
  • <thead>, <tbody>: agrupan encabezado y cuerpo (opcional pero recomendado).
<table>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>28</td>
  </tr>
</table>
5 Laboratorio: tabla de productos

Construye una tabla con encabezados "Producto" y "Precio", y agrega dos filas de datos con productos inventados.

Ver solución sugerida
<body>

    <tr><td>Cuaderno</td><td>$5</td></tr>
    <tr><td>Lápiz</td><td>$1</td></tr>
  </table>
</body>
06 · <form>

Formularios

Los formularios capturan datos del usuario. Piezas clave:

  • <form>: contenedor; define a dónde y cómo enviar los datos.
  • <input type="...">: campo de entrada. Tipos comunes: text, email, password, checkbox, radio, date.
  • <label>: etiqueta accesible asociada a un input mediante for/id.
  • <select> + <option>: menú desplegable. <textarea>: texto largo. <button>: botón de acción.
<form>
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre">

  <button type="submit">Enviar</button>
</form>
6 Laboratorio: formulario de contacto

Crea un formulario con: un campo de texto para "Nombre" (con su label), un campo email para "Correo", un textarea para "Mensaje" y un botón para enviar.

Ver solución sugerida
<body>
  <form>
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre"><br>
    <label for="correo">Correo:</label>
    <input type="email" id="correo"><br>
    <label for="msg">Mensaje:</label><br>
    <textarea id="msg"></textarea><br>
    <button type="submit">Enviar</button>
  </form>
</body>
07 · <section>

Elementos semánticos de HTML5

Antes de HTML5 casi todo se hacía con <div>. Hoy existen etiquetas que describen el rol de cada bloque, lo que mejora accesibilidad y SEO:

  • <header>: cabecera de la página o de una sección.
  • <nav>: bloque de navegación (menús, enlaces).
  • <main>: contenido principal (uno por página).
  • <section>: agrupa contenido temáticamente relacionado.
  • <article>: contenido autocontenido (un post, una noticia).
  • <aside>: contenido secundario (barra lateral).
  • <footer>: pie de página.
<header>
  <nav>Inicio | Blog | Contacto</nav>
</header>
<main>
  <article>
    <h1>Título del post</h1>
    <p>Contenido...</p>
  </article>
</main>
<footer>© 2026</footer>
7 Laboratorio: página semántica

Arma el esqueleto de una mini página de blog usando <header> con un <nav>, un <main> con un <article>, y un <footer>.

Ver solución sugerida
<body>
  <header>
    <nav>Inicio | Blog | Contacto</nav>
  </header>
  <main>
    <article>
      <h1>Cómo aprendí HTML</h1>
      <p>Practicando todos los días.</p>
    </article>
  </main>
  <footer>© 2026 Mi Blog</footer>
</body>
08 · buenas prácticas

Buenas prácticas y siguientes pasos

  • Usa siempre alt descriptivo en imágenes y lang en <html>.
  • Elige etiquetas por su significado, no por cómo se ven (eso es trabajo del CSS).
  • Indenta tu código de forma consistente; facilita detectar etiquetas sin cerrar.
  • Valida tu HTML con el validador del W3C.
  • Un solo <h1> por página, y no saltes niveles de encabezado (de h2 a h4 sin h3).
