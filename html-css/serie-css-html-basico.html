Cómo usar CSS junto con HTML

Seis pasos muy pequeños, uno a la vez. Cada uno te enseña una sola idea sobre cómo conectar CSS con HTML y aplicar selectores básicos. No hay que saltarse ninguno: cada paso se apoya en el anterior.

1. Estilo en línea 2. Estilo interno 3. Estilo externo 4. Selector de etiqueta 5. Selector de clase 6. Selector de id
1

CSS en línea (inline)

La forma más directa de aplicar CSS: el atributo style="..." dentro de la propia etiqueta. Solo afecta a ese elemento. Es rápido, pero poco escalable — evítalo en proyectos grandes.

Tarea: al párrafo dale color purple usando style="color: purple;" directamente en la etiqueta <p>.
Ver solución
<body>
  <p style="color: purple;">Este texto debería ser morado.</p>
</body>
2

CSS interno (con <style>)

En vez de repetir style="..." en cada etiqueta, puedes escribir todas las reglas juntas dentro de un bloque <style> en el <head>. Así un solo selector puede afectar a varios elementos a la vez.

Tarea: dentro de <style>, escribe la regla p { color: teal; } para que los dos párrafos cambien de color sin tocar el HTML.
Ver solución
<style>
p {
  color: teal;
}
</style>
3

CSS externo (con <link>)

En proyectos reales, el CSS vive en su propio archivo (por ejemplo estilos.css) y se conecta al HTML con una etiqueta <link> dentro del <head>. Es la forma recomendada: separa contenido y estilo, y el mismo archivo CSS puede reutilizarse en varias páginas.

Tarea: este editor no puede cargar un archivo aparte, así que en vez de escribirlo tú completa el <link> que faltaría en el <head> para vincular estilos.css. Como aquí no existe ese archivo, el resultado no cambiará — el objetivo es memorizar la sintaxis correcta.
Ver solución
<head>
  <link rel="stylesheet" href="estilos.css">
</head>
4

Selector de etiqueta

El selector más simple: el nombre de la etiqueta, sin puntos ni almohadillas. Aplica la regla a todos los elementos de ese tipo en la página.

Tarea: usando el selector li, dale a todos los elementos de la lista fondo #e8f0ff y un poco de padding: 6px.
Ver solución
<style>
li {
  background: #e8f0ff;
  padding: 6px;
}
</style>
5

Selector de clase

Una clase se escribe en el HTML como class="nombre" y en el CSS se selecciona con un punto: .nombre. A diferencia del selector de etiqueta, solo afecta a los elementos que tengan esa clase — y una clase puede reutilizarse en varios elementos distintos.

Tarea: usando el selector .aviso, dale a esos elementos texto en color crimson y font-weight: bold.
Ver solución
<style>
.aviso {
  color: crimson;
  font-weight: bold;
}
</style>
6

Selector de id

Un id se escribe como id="nombre" y se selecciona con una almohadilla: #nombre. A diferencia de la clase, un id debe existir una sola vez por página — se usa para un elemento único, como la cabecera principal.

Tarea: usando el selector #titulo-principal, dale al encabezado con ese id un tamaño de font-size: 32px y color #4d8dff.
Ver solución
<style>
#titulo-principal {
  font-size: 32px;
  color: #4d8dff;
}
</style>
