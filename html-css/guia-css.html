Dale estilo a tu HTML con CSS.

Igual que la guía de HTML: teoría breve + laboratorio en vivo. Aquí el HTML ya viene armado — tu trabajo es escribir el CSS y ver cómo cambia el resultado al instante.

01 · sintaxis

¿Qué es CSS y cómo se vincula?

CSS (Cascading Style Sheets) define la presentación de un documento HTML: colores, tamaños, espaciados, posiciones. Una regla CSS tiene un selector (a qué elementos aplica) y un bloque de declaraciones (propiedad: valor;).

  • Externo (recomendado): <link rel="stylesheet" href="estilos.css"> dentro del <head>.
  • Interno: un bloque <style> dentro del <head>.
  • En línea: atributo style="..." en la propia etiqueta (evítalo salvo casos puntuales).
p {
  color: navy;
  font-size: 18px;
}
1 Laboratorio: primeras reglas

Este documento ya tiene un <h1> y un <p>. Escribe CSS dentro de <style> para poner el h1 en color tomato y el p con font-size: 20px.

Ver solución sugerida
<style>
h1 { color: tomato; }
p { font-size: 20px; }
</style>
02 · selectores

Selectores

Elegir bien el selector es la mitad del trabajo en CSS:

  • elemento: aplica a todas las etiquetas de ese tipo. Ej: p { }.
  • .clase: aplica a elementos con class="clase". Se puede reutilizar en varios elementos.
  • #id: aplica a un único elemento con ese id.
  • A B: selector descendiente (B dentro de A). A > B: hijo directo.
  • Pseudo-clases: :hover, :first-child, :nth-child().
/* clase */
.destacado { background: yellow; }

/* id */
#logo { width: 120px; }

/* pseudo-clase */
a:hover { color: crimson; }
2 Laboratorio: clases e id

Hay tres <li>; uno tiene class="destacado" y otro id="especial". Dale fondo amarillo a .destacado y texto en negrita a #especial.

Ver solución sugerida
<style>
.destacado { background: yellow; }
#especial { font-weight: bold; }
</style>
03 · box model

El modelo de caja (box model)

Todo elemento HTML es una caja rectangular formada por cuatro capas, de adentro hacia afuera:

  • content: el contenido (texto, imagen).
  • padding: espacio interno entre el contenido y el borde.
  • border: el borde de la caja.
  • margin: espacio externo, entre esta caja y las demás.

Con box-sizing: border-box, el width incluye padding y border (evita sorpresas de tamaño). Es una práctica casi universal.

.caja {
  box-sizing: border-box;
  width: 200px;
  padding: 16px;
  border: 2px solid #333;
  margin: 12px;
}
3 Laboratorio: construye una caja

Al .card dale: width: 220px, padding: 20px, border: 3px solid #4d8dff y margin: 20px. Usa box-sizing: border-box.

Ver solución sugerida
<style>
.card {
  box-sizing: border-box;
  width: 220px;
  padding: 20px;
  border: 3px solid #4d8dff;
  margin: 20px;
}
</style>
04 · color y tipografía

Colores, tipografía y fondos

  • Colores: nombres (tomato), hex (#ff6347), rgb() o rgba() con transparencia.
  • Tipografía: font-family, font-size, font-weight, line-height, text-align.
  • Fondos: background-color, background-image, background-size: cover.
body {
  font-family: "Segoe UI", sans-serif;
  color: #222;
  background-color: #f4f4f4;
}

h1 {
  font-weight: 700;
  text-align: center;
}
4 Laboratorio: estilo de texto

Dale a body fondo #1e1e2e y texto blanco. Centra el h1 y ponle font-size: 40px.

Ver solución sugerida
<style>
body { background-color: #1e1e2e; color: white; }
h1 { text-align: center; font-size: 40px; }
</style>
05 · display: flex

Flexbox

Flexbox organiza elementos en una fila o columna, repartiendo espacio y alineando con facilidad. Se activa en el contenedor con display: flex:

  • flex-direction: row (por defecto) o column.
  • justify-content: alinea en el eje principal (center, space-between...).
  • align-items: alinea en el eje cruzado (center, stretch...).
  • gap: espacio entre elementos hijos.
.contenedor {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}
5 Laboratorio: barra de navegación

Haz que .navbar use flexbox para poner sus 3 enlaces en fila, separados con justify-content: space-around, y centrados verticalmente.

Ver solución sugerida
.navbar {
  height: 60px;
  background: #212748;
  display: flex;
  justify-content: space-around;
  align-items: center;
}
06 · display: grid

CSS Grid

Grid organiza contenido en dos dimensiones (filas y columnas a la vez), ideal para layouts completos:

  • display: grid activa la cuadrícula en el contenedor.
  • grid-template-columns: 1fr 1fr 1fr: 3 columnas de ancho igual (fr = fracción del espacio disponible).
  • gap: separación entre celdas.
  • grid-template-columns: repeat(3, 1fr) es un atajo equivalente al ejemplo anterior.
.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
6 Laboratorio: galería en cuadrícula

Convierte .galeria en un grid de 3 columnas iguales con gap: 10px, para que las 6 cajas se acomoden en 2 filas.

Ver solución sugerida
.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
07 · position

Posicionamiento

  • static: valor por defecto, sigue el flujo normal.
  • relative: se desplaza respecto a su posición original, sin sacar a los demás del flujo.
  • absolute: se posiciona respecto al ancestro posicionado más cercano (o al documento).
  • fixed: se posiciona respecto a la ventana; no se mueve al hacer scroll.
  • sticky: se comporta como relative hasta cierto punto de scroll, luego queda "pegado".
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
7 Laboratorio: insignia posicionada

El .tarjeta ya tiene position: relative. Coloca .badge con position: absolute en la esquina superior derecha (top: 8px; right: 8px;).

Ver solución sugerida
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
  background: #f5a623;
  color: #10142a;
  padding: 4px 8px;
  border-radius: 6px;
  font-weight: bold;
}
08 · @media

Diseño responsive

Un sitio responsive se adapta a distintos tamaños de pantalla:

  • Unidades relativas: %, em, rem, vw/vh, en vez de valores fijos en px cuando sea posible.
  • Media queries: aplican reglas CSS solo cuando se cumple una condición de pantalla.
  • Regla práctica: diseña primero para móvil ("mobile-first") y añade reglas para pantallas más grandes con min-width.
.columnas {
  display: grid;
  grid-template-columns: 1fr;
}

/* en pantallas de 600px o más, 2 columnas */
@media (min-width: 600px) {
  .columnas {
    grid-template-columns: 1fr 1fr;
  }
}
8 Reto final: layout adaptable

Haz que .columnas sea de 1 sola columna por defecto (para móvil), y que a partir de min-width: 500px pase a 2 columnas. Redimensiona la ventana del navegador (o el iframe) para comprobarlo — aquí puedes probarlo cambiando el ancho del body mentalmente, ¡el código es lo que importa!

Ver solución sugerida
.columnas {
  display: grid;
  grid-template-columns: 1fr;
  gap: 10px;
}
@media (min-width: 500px) {
  .columnas {
    grid-template-columns: 1fr 1fr;
  }
}
