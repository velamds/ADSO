¿Qué es el DOM?

Cuando el navegador carga una página HTML, construye en memoria una representación de esa página en forma de árbol de objetos: el DOM (Document Object Model). JavaScript puede leer y modificar ese árbol: cambiar texto, estilos, crear elementos nuevos o eliminarlos. Eso es "manipular el DOM".

En esta guía vas a practicar con 5 ejercicios, cada uno con una demo en vivo que puedes probar, el código completo para transcribir, la explicación de cada línea y un checkpoint para comprobar que entendiste.

🔒 El código de los ejercicios está bloqueado para copiar y pegar a propósito. La idea es que lo transcribas a mano en tu propio editor: escribir cada línea te obliga a leerla con atención y ayuda mucho más a memorizar la sintaxis que un copiar-pegar.
Ejercicio 1

Seleccionar un elemento y cambiar su texto

Aprenderás a "atrapar" un elemento del HTML desde JavaScript usando su id, y a cambiar el texto que muestra.

Demo en vivo

Hola, soy un título

HTML para transcribir

index.html HTML 🔒
01<h2 id="titulo">Hola, soy un título</h2>
02<button id="btnCambiar">Cambiar texto</button>
01

Un encabezado <h2> con id="titulo". Ese id es el "nombre único" que usaremos desde JavaScript para encontrarlo.

02

Un botón con id="btnCambiar". Al hacer clic en él, va a ejecutarse nuestra función de JavaScript.

JavaScript para transcribir

script.js JavaScript 🔒
01const titulo = document.getElementById("titulo");
02const boton = document.getElementById("btnCambiar");
03
04boton.addEventListener("click", function () {
05  titulo.textContent = "¡El texto ha cambiado!";
06});
01

document representa toda la página. document.getElementById("titulo") busca el elemento cuyo id es "titulo" y lo guarda en la constante titulo. A partir de aquí, la palabra titulo en el código ES ese elemento del HTML.

02

Lo mismo, pero para el botón: buscamos el elemento con id="btnCambiar" y lo guardamos en boton.

04

addEventListener significa "escuchar un evento". Aquí le decimos al botón: "cuando ocurra un click, ejecuta la función que viene a continuación". Esa función (sin nombre, por eso se llama función anónima) es el segundo argumento.

05

textContent es una propiedad de cualquier elemento que representa su texto visible. Al asignarle un nuevo valor con =, reemplazamos el texto que tenía el <h2> por el nuevo.

06

Cerramos primero la función (}) y luego los paréntesis de addEventListener(...) con ), y terminamos la instrucción con ;.

🧩 Checkpoint 1

Si en el HTML cambias id="btnCambiar" por id="botonCambiar" pero olvidas actualizar el JavaScript, ¿qué va a pasar?

Ejercicio 2

Cambiar estilos con JavaScript

Verás dos formas de cambiar la apariencia de un elemento: modificando su estilo directamente (style) o activando/desactivando una clase CSS (classList).

Demo en vivo

Soy una caja

HTML para transcribir

index.htmlHTML🔒
01<div id="caja" class="caja">Soy una caja</div>
02<button id="btnColor">Cambiar color</button>
03<button id="btnResaltar">Activar/Desactivar resaltado</button>
01

El <div> tiene dos atributos: id="caja" (para seleccionarlo desde JS) y class="caja" (para darle estilo desde CSS). Son cosas distintas: el id es único en la página, la class se puede repetir en varios elementos.

02

Botón que cambiará el color de fondo de la caja.

03

Botón que activará o desactivará una clase CSS de resaltado.

CSS para transcribir

estilos.cssCSS🔒
01.caja {
02  padding: 20px;
03  background-color: #eceefb;
04  border-radius: 8px;
05  transition: background-color 0.3s;
06}
07
08.resaltado {
09  border: 3px solid orange;
10  font-weight: bold;
11}
01

.caja con un punto selecciona cualquier elemento que tenga class="caja", y define su apariencia inicial.

05

transition hace que el cambio de color se vea suave (0.3 segundos) en lugar de instantáneo.

08

.resaltado es una clase que no está puesta en el HTML desde el principio. JavaScript la va a agregar o quitar dinámicamente.

JavaScript para transcribir

script.jsJavaScript🔒
01const caja = document.getElementById("caja");
02const btnColor = document.getElementById("btnColor");
03const btnResaltar = document.getElementById("btnResaltar");
04
05btnColor.addEventListener("click", function () {
06  caja.style.backgroundColor = "lightblue";
07});
08
09btnResaltar.addEventListener("click", function () {
10  caja.classList.toggle("resaltado");
11});
01

Guardamos la caja en una variable, igual que en el ejercicio 1.

02

Guardamos el botón de color.

03

Guardamos el botón de resaltado.

06

caja.style.backgroundColor cambia directamente el estilo en línea del elemento (como si escribieras style="background-color: lightblue" en el HTML). Nota que en JS la propiedad se escribe en "camelCase" (backgroundColor), mientras que en CSS se escribe con guion (background-color).

10

classList.toggle("resaltado") es un interruptor: si la caja no tiene la clase resaltado, la agrega; si ya la tiene, la quita. Por eso cada clic activa o desactiva el efecto.

🧩 Checkpoint 2

¿Cuál es la principal ventaja de usar classList.toggle() en vez de cambiar style directamente?

Ejercicio 3

Crear elementos dinámicamente

Vas a construir una mini lista de frutas: el usuario escribe un nombre y JavaScript crea un nuevo elemento <li> y lo agrega a la lista.

Demo en vivo

    HTML para transcribir

    index.htmlHTML🔒
    01<input type="text" id="inputFruta" placeholder="Escribe una fruta">
    02<button id="btnAgregar">Agregar</button>
    03<ul id="listaFrutas"></ul>
    01

    Un campo de texto. placeholder es el texto gris de ejemplo que se ve cuando está vacío; no es su valor real.

    02

    El botón que dispara la acción de agregar.

    03

    Una lista <ul> completamente vacía. Cada fruta que agreguemos se convertirá en un <li> dentro de ella.

    JavaScript para transcribir

    script.jsJavaScript🔒
    01const input = document.getElementById("inputFruta");
    02const boton = document.getElementById("btnAgregar");
    03const lista = document.getElementById("listaFrutas");
    04
    05boton.addEventListener("click", function () {
    06  const texto = input.value;
    07
    08  if (texto === "") {
    09    return;
    10  }
    11
    12  const item = document.createElement("li");
    13  item.textContent = texto;
    14  lista.appendChild(item);
    15
    16  input.value = "";
    17});
    01

    Guardamos el campo de texto en input.

    02

    Guardamos el botón en boton.

    03

    Guardamos la lista <ul> en lista.

    06

    input.value lee lo que el usuario escribió en el campo de texto en este momento, y lo guarda en texto.

    08-10

    Comprobamos si texto está vacío. Si es así, return termina la función inmediatamente, sin crear ningún elemento. Esto evita agregar frutas "en blanco" a la lista.

    12

    document.createElement("li") crea un nuevo elemento <li> en memoria. Todavía no se ve en la página: solo existe como un objeto de JavaScript.

    13

    Le damos contenido al <li> asignando el texto que escribió el usuario.

    14

    lista.appendChild(item) inserta ese <li> como el último hijo de la lista. Este es el paso que realmente lo hace aparecer en la página; sin él, el elemento creado en la línea 12 nunca se vería.

    16

    Vaciamos el campo de texto asignándole una cadena vacía, para que quede listo para escribir la siguiente fruta.

    🧩 Checkpoint 3

    Si borras la línea lista.appendChild(item); pero dejas todo lo demás igual, ¿qué pasará al hacer clic en "Agregar"?

    Ejercicio 4

    Eliminar elementos del DOM

    Vamos a mejorar la lista del ejercicio anterior agregando un botón "❌" a cada fruta, para poder eliminarla.

    Demo en vivo

      HTML para transcribir

      index.htmlHTML🔒
      01<input type="text" id="inputFruta" placeholder="Escribe una fruta">
      02<button id="btnAgregar">Agregar</button>
      03<ul id="listaFrutas"></ul>
      01-03

      Exactamente el mismo HTML del ejercicio 3. Lo único que cambia es el JavaScript: ahora cada <li> creado incluirá también su propio botón de borrar.

      JavaScript para transcribir

      script.jsJavaScript🔒
      01const input = document.getElementById("inputFruta");
      02const boton = document.getElementById("btnAgregar");
      03const lista = document.getElementById("listaFrutas");
      04
      05boton.addEventListener("click", function () {
      06  const texto = input.value;
      07  if (texto === "") return;
      08
      09  const item = document.createElement("li");
      10  item.textContent = texto;
      11
      12  const btnBorrar = document.createElement("button");
      13  btnBorrar.textContent = "❌";
      14
      15  btnBorrar.addEventListener("click", function () {
      16    item.remove();
      17  });
      18
      19  item.appendChild(btnBorrar);
      20  lista.appendChild(item);
      21
      22  input.value = "";
      23});
      01-10

      Igual que en el ejercicio 3: seleccionamos los elementos, leemos el texto, validamos que no esté vacío y creamos el <li> con su texto.

      12

      Creamos un nuevo elemento <button> en memoria: será el botón de borrar de esta fruta en particular.

      13

      Le ponemos como texto el emoji "❌", para que se vea como un botón de eliminar.

      15-17

      Le agregamos su propio addEventListener a este botón, en el mismo momento en que lo creamos. Cuando se haga clic en él, se ejecutará item.remove(). Como item es la variable del <li> que estamos construyendo en esta misma vuelta del clic, cada botón de borrar "recuerda" a cuál fruta pertenece (esto se llama closure, o cierre).

      16

      item.remove() es un método moderno que elimina el elemento directamente del DOM, sin necesidad de preguntarle a su elemento padre.

      19

      Metemos el botón de borrar dentro del <li>, como su hijo.

      20

      Ahora sí, insertamos el <li> completo (con su texto y su botón de borrar ya dentro) en la lista.

      🧩 Checkpoint 4

      ¿Por qué el botón "❌" de cada fruta borra esa fruta específica y no otra?

      Ejercicio 5

      Formulario con validación básica

      Ejercicio final: un formulario que valida que el usuario haya escrito su nombre antes de mostrar un mensaje de bienvenida, evitando que la página se recargue.

      Demo en vivo

      HTML para transcribir

      index.htmlHTML🔒
      01<form id="formNombre">
      02  <input type="text" id="inputNombre" placeholder="Tu nombre">
      03  <button type="submit">Enviar</button>
      04</form>
      05<p id="mensaje"></p>
      01

      <form> agrupa el campo y el botón; cuando el botón dentro de él tiene type="submit", hacer clic dispara automáticamente el evento submit del formulario.

      02

      Campo donde el usuario escribe su nombre.

      03

      type="submit" convierte este botón en el "botón de envío" del formulario.

      05

      Un párrafo vacío donde vamos a mostrar el mensaje de bienvenida o de error.

      JavaScript para transcribir

      script.jsJavaScript🔒
      01const formulario = document.getElementById("formNombre");
      02const inputNombre = document.getElementById("inputNombre");
      03const mensaje = document.getElementById("mensaje");
      04
      05formulario.addEventListener("submit", function (evento) {
      06  evento.preventDefault();
      07
      08  const nombre = inputNombre.value.trim();
      09
      10  if (nombre === "") {
      11    mensaje.textContent = "Por favor escribe tu nombre.";
      12    mensaje.style.color = "red";
      13    return;
      14  }
      15
      16  mensaje.textContent = "¡Hola, " + nombre + "! Bienvenido.";
      17  mensaje.style.color = "green";
      18  inputNombre.value = "";
      19});
      01-03

      Seleccionamos el formulario, el campo de nombre y el párrafo de mensaje, como en los ejercicios anteriores.

      05

      Escuchamos el evento "submit" del formulario. Esta vez la función sí recibe un parámetro, al que llamamos evento: es un objeto que el navegador crea automáticamente con información sobre lo que ocurrió.

      06

      evento.preventDefault() cancela el comportamiento por defecto de un formulario, que es recargar la página al enviarse. Sin esta línea, la página se recargaría y perderíamos el control con JavaScript.

      08

      Leemos el valor del campo con .value y le aplicamos .trim(), un método que quita espacios en blanco al inicio y al final (así " Ana " se convierte en "Ana").

      10-14

      Si después de quitar espacios el nombre quedó vacío, mostramos un mensaje de error en rojo y salimos de la función con return, sin llegar a mostrar el mensaje de bienvenida.

      16

      Si el nombre sí es válido, construimos el mensaje de bienvenida uniendo texto y variable con el operador +.

      17

      Pintamos el mensaje de verde para indicar éxito.

      18

      Limpiamos el campo de texto para dejarlo listo por si se quiere volver a usar.

      🧩 Checkpoint 5

      ¿Qué pasaría si quitas la línea evento.preventDefault();?
