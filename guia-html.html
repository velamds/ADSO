Estructura básica de un documento HTML

HTML (HyperText Markup Language) es el lenguaje base de toda página web. Funciona con etiquetas que envuelven el contenido.

Esqueleto mínimo

<!-- Todo documento HTML empieza así -->
<!DOCTYPE html>
<html lang="es">

  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
  </head>

  <body>
    <h1>¡Hola, mundo!</h1>
    <p>Esta es mi primera página web.</p>
  </body>

</html>
EtiquetaFunción
<!DOCTYPE html>Le dice al navegador que es HTML5
<html>Raíz del documento
<head>Metadatos — no se ve en pantalla
<title>Título de la pestaña del navegador
<body>Todo el contenido visible
Tip: Los atributos van siempre dentro de la etiqueta de apertura: <etiqueta atributo="valor">

Enlaces (hipervínculos)

Los enlaces son la esencia de la web. Se crean con la etiqueta <a> y su atributo href.

<!-- Enlace externo -->
<a href="https://ejemplo.com">Visitar ejemplo</a>

<!-- Abrir en nueva pestaña -->
<a href="https://ejemplo.com" target="_blank">Nueva pestaña</a>

<!-- Enlace a otra página del mismo sitio -->
<a href="contacto.html">Contacto</a>

<!-- Ancla: saltar a una sección de la misma página -->
<a href="#seccion">Ir a sección</a>
<h2 id="seccion">La sección</h2>

<!-- Enlace de email -->
<a href="mailto:hola@ejemplo.com">Enviar email</a>

<!-- Enlace de teléfono -->
<a href="tel:+521234567890">Llamar</a>
Tip: Siempre usa rel="noopener" junto con target="_blank" por seguridad: <a href="..." target="_blank" rel="noopener">

Imágenes

La etiqueta <img> inserta imágenes. Es una etiqueta vacía (no tiene cierre).

<!-- Imagen desde URL -->
<img
  src="https://via.placeholder.com/300x200"
  alt="Descripción de la imagen"
  width="300"
  height="200"
>

<!-- Imagen local -->
<img src="fotos/paisaje.jpg" alt="Un paisaje">

<!-- Figura con pie de foto -->
<figure>
  <img src="foto.jpg" alt="Mi foto">
  <figcaption>Esta es mi foto</figcaption>
</figure>

<!-- Imagen que es un enlace -->
<a href="https://ejemplo.com">
  <img src="logo.png" alt="Logo de Ejemplo">
</a>
Importante: El atributo alt es obligatorio. Describe la imagen para lectores de pantalla y cuando la imagen no carga. Si es puramente decorativa, usa alt="".

5

Listas

Hay tres tipos de listas en HTML: desordenadas, ordenadas y de definición.

<!-- Lista desordenada (viñetas) -->
<ul>
  <li>Manzana</li>
  <li>Naranja</li>
  <li>Plátano</li>
</ul>

<!-- Lista ordenada (numerada) -->
<ol>
  <li>Primero</li>
  <li>Segundo</li>
  <li>Tercero</li>
</ol>

<!-- Lista anidada -->
<ul>
  <li>Frutas
    <ul>
      <li>Manzana</li>
      <li>Pera</li>
    </ul>
  </li>
  <li>Verduras</li>
</ul>

<!-- Lista de definición -->
<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para páginas web.</dd>
  <dt>CSS</dt>
  <dd>Lenguaje de estilos para darle diseño al HTML.</dd>
</dl>

Tablas

Las tablas se usan para mostrar datos en filas y columnas. Nunca para maquetar la página.

<table border="1">

  <!-- Encabezado de tabla -->
  <thead>
    <tr>
      <th>Nombre</th>
      <th>Edad</th>
      <th>Ciudad</th>
    </tr>
  </thead>

  <!-- Cuerpo de tabla -->
  <tbody>
    <tr>
      <td>Ana</td>
      <td>28</td>
      <td>Madrid</td>
    </tr>
    <tr>
      <td>Luis</td>
      <td>35</td>
      <td colspan="1">México DF</td>
    </tr>
  </tbody>

  <!-- Pie de tabla -->
  <tfoot>
    <tr>
      <td colspan="3">Total: 2 personas</td>
    </tr>
  </tfoot>

</table>
AtributoUso
colspan="N"La celda ocupa N columnas
rowspan="N"La celda ocupa N filas
scope="col/row"Accesibilidad en <th>

Formularios

Los formularios permiten al usuario enviar datos. Son esenciales para login, búsqueda, registros, etc.

<form action="/enviar" method="post">

  <!-- Texto -->
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" placeholder="Tu nombre" required>

  <!-- Email -->
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

  <!-- Contraseña -->
  <input type="password" name="pass" minlength="8">

  <!-- Número y rango -->
  <input type="number" min="0" max="100">
  <input type="range"  min="0" max="10">

  <!-- Opciones -->
  <select name="pais">
    <option value="mx">México</option>
    <option value="es">España</option>
  </select>

  <!-- Radio y checkbox -->
  <input type="radio" name="genero" value="m"> Masculino
  <input type="radio" name="genero" value="f"> Femenino
  <input type="checkbox" name="terms"> Acepto términos

  <!-- Área de texto -->
  <textarea name="mensaje" rows="4" cols="40"></textarea>

  <!-- Botones -->
  <button type="submit">Enviar</button>
  <button type="reset">Limpiar</button>

</form>

HTML Semántico

El HTML semántico usa etiquetas con significado. Mejora la accesibilidad, el SEO y la legibilidad del código.

<body>

  <header>
    <!-- Logo, nombre del sitio, menú principal -->
    <nav>
      <a href="/">Inicio</a>
      <a href="/blog">Blog</a>
    </nav>
  </header>

  <main>
    <article>
      <h1>Título del artículo</h1>
      <time datetime="2026-06-01">1 de junio, 2026</time>
      <p>Contenido principal del artículo...</p>
    </article>

    <aside>
      <!-- Barra lateral: artículos relacionados, publicidad -->
      <h2>Relacionados</h2>
    </aside>
  </main>

  <section>
    <!-- Sección temática de la página -->
    <h2>Comentarios</h2>
  </section>

  <footer>
    <p>&copy; 2026 Mi Sitio</p>
    <address>
      Contacto: <a href="mailto:info@misitio.com">info@misitio.com</a>
    </address>
  </footer>

</body>
EtiquetaCuándo usarla
<header>Cabecera de la página o de una sección
<nav>Menú de navegación principal
<main>Contenido principal (solo uno por página)
<article>Contenido independiente (post, noticia)
<section>Sección temática con encabezado propio
<aside>Contenido complementario / barra lateral
<footer>Pie de página o de sección
<div>Contenedor genérico (cuando nada semántico encaja)
<span>Contenedor en línea genérico
Tip: Si te preguntas "¿uso div o algo semántico?", pregúntate: ¿tiene significado propio este bloque? Si es un artículo, una sección, un header — úsalo. Si es solo un contenedor de layout, usa div.
