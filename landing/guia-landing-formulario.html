Paso 2 / 5

Reset y estilos globales

Antes de estilizar cada sección, se fijan reglas base que afectan a toda la página: tipografía, colores de fondo y una regla de reset muy común para que el tamaño de las cajas sea predecible.

estilos.css
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: "Segoe UI", sans-serif;
  color: #1f2333;
  background: #fafafc;
  line-height: 1.5;
}
¿Qué hace cada regla?
box-sizing: border-boxHace que el width/height de cualquier caja incluya su padding y border, en vez de sumarse aparte. Evita que los elementos "se desborden" al agregarles espacio interno.
margin: 0 / padding: 0Elimina los espacios por defecto que el navegador aplica a etiquetas como <body>, <h1> o <p>, para partir de un lienzo predecible.
font-familyDefine la tipografía de toda la página (se hereda a los elementos hijos salvo que se sobreescriba).
color / backgroundColor de texto y de fondo por defecto para todo el body.
line-height: 1.5Espaciado vertical entre líneas de texto — mejora la legibilidad de los párrafos.

Paso 3 / 5

Header y hero

El header usa Flexbox para separar el logo de los enlaces. El hero usa display: grid con dos columnas para poner el texto junto a la imagen.

estilos.css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 20px 48px;
  background: white;
}
.nav a { margin-left: 24px; text-decoration: none; color: #1f2333; }
.logo { font-weight: 800; font-size: 1.3rem; }

.hero {
  display: grid;
  grid-template-columns: 1fr 1fr;
  align-items: center;
  gap: 40px;
  padding: 60px 48px;
}
.hero h1 { font-size: 2.4rem; margin-bottom: 16px; }
.hero p { color: #5b6180; margin-bottom: 24px; }
.hero img { width: 100%; border-radius: 16px; }

.btn {
  display: inline-block;
  background: #a78bfa;
  color: white;
  padding: 12px 24px;
  border-radius: 8px;
  text-decoration: none;
  font-weight: 600;
}
¿Qué hace cada regla?
.nav → display: flexColoca logo y navegación en fila. justify-content: space-between empuja el logo a la izquierda y los enlaces a la derecha. align-items: center los alinea verticalmente.
.nav a → text-decoration: noneQuita el subrayado por defecto de los enlaces. margin-left separa un enlace del siguiente.
.hero → grid-template-columns: 1fr 1frDivide el hero en dos columnas de igual ancho: texto a la izquierda, imagen a la derecha. gap separa ambas columnas.
.hero img → width: 100%Hace que la imagen llene su columna en vez de mostrarse en su tamaño original. border-radius le redondea las esquinas.
.btndisplay: inline-block permite aplicar padding y mantenerlo en línea con el texto; el resto son estilos visuales del botón (color, relleno, esquinas redondeadas).

Paso 4 / 5

Tarjetas de características y CTA

Las tres tarjetas usan display: grid con columnas repetidas. La sección CTA (call to action) es un bloque de fondo sólido, centrado, para captar la atención justo antes del footer.

estilos.css
.features {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
  padding: 40px 48px;
}
.card {
  background: white;
  border-radius: 14px;
  padding: 24px;
  box-shadow: 0 4px 16px rgba(0,0,0,0.06);
  transition: transform 0.2s ease;
}
.card:hover { transform: translateY(-4px); }

.cta {
  background: #1f2333;
  color: white;
  text-align: center;
  padding: 60px 24px;
}
.cta h2 { margin-bottom: 20px; }
¿Qué hace cada regla?
.features → repeat(3, 1fr)Atajo para crear 3 columnas de ancho igual, sin escribir 1fr 1fr 1fr a mano.
.card → box-shadowAgrega una sombra suave (desplazamiento, difuminado y color con transparencia) que le da a la tarjeta sensación de "estar elevada".
.card → transition + :hovertransition hace que los cambios de transform ocurran suavemente en 0.2 segundos, en vez de saltar de golpe. Al pasar el mouse (:hover), la tarjeta sube 4px.
.cta → text-align: centerCentra el texto dentro del bloque; combinado con el fondo oscuro, crea contraste para destacar la llamada a la acción.

Paso 5 / 5 · Reto final

Footer, responsive y playground editable

Se estiliza el footer y se agrega una @media query para que el hero y las tarjetas se apilen en pantallas angostas. Desde aquí puedes editar libremente todo el código de la landing.

estilos.css
footer {
  text-align: center;
  padding: 24px;
  color: #8a90ad;
  font-size: .9rem;
}

/* pantallas angostas: apilar en una columna */
@media (max-width: 700px) {
  .hero { grid-template-columns: 1fr; }
  .features { grid-template-columns: 1fr; }
  .nav { flex-direction: column; gap: 12px; }
}
¿Qué hace cada regla?
@media (max-width: 700px)Todo lo que esté dentro de estas llaves solo se aplica cuando el ancho de la pantalla es de 700px o menos — así el diseño se adapta a celulares.
grid-template-columns: 1frReduce el hero y las tarjetas a una sola columna, apilando el contenido verticalmente en vez de mostrarlo lado a lado.
.nav → flex-direction: columnCambia el eje del flex de fila a columna, para que el logo quede arriba de los enlaces en pantallas pequeñas.

Formulario

Estructura, layout de campos, estados de foco y validación, botón y responsive.

Paso 1 / 5

Estructura HTML del formulario

Cada campo se envuelve en un <div class="field"> con su <label> asociado por for/id. Esto facilita estilizar cada fila de forma consistente.

index.html
<form class="formulario">
  <h2>Crea tu cuenta</h2>

  <div class="row">
    <div class="field">
      <label for="nombre">Nombre</label>
      <input type="text" id="nombre" required>
    </div>
    <div class="field">
      <label for="correo">Correo</label>
      <input type="email" id="correo" required>
    </div>
  </div>

  <div class="field">
    <label for="plan">Plan</label>
    <select id="plan">
      <option>Básico</option>
      <option>Pro</option>
    </select>
  </div>

  <div class="field checkbox">
    <input type="checkbox" id="terminos">
    <label for="terminos">Acepto los términos</label>
  </div>

  <button type="submit">Crear cuenta</button>
</form>

Paso 2 / 5

La tarjeta contenedora

El formulario completo vive dentro de una "tarjeta" centrada: ancho máximo, fondo blanco, esquinas redondeadas y sombra. Es el mismo patrón visual que las tarjetas de la landing.

estilos.css
body {
  display: flex;
  justify-content: center;
  background: #f2f0fa;
  min-height: 100vh;
  padding: 40px 16px;
}

.formulario {
  background: white;
  width: 100%;
  max-width: 420px;
  border-radius: 16px;
  padding: 32px;
  box-shadow: 0 8px 30px rgba(0,0,0,0.08);
}
.formulario h2 { margin-bottom: 20px; }
¿Qué hace cada regla?
body → display: flex + justify-content: centerCentra horizontalmente la tarjeta del formulario dentro de toda la pantalla.
min-height: 100vhvh = "viewport height". 100vh asegura que el body ocupe como mínimo toda la altura visible de la ventana, para poder centrar verticalmente si se combina con más reglas.
.formulario → max-width: 420pxEvita que la tarjeta se estire demasiado en pantallas grandes; en pantallas pequeñas, width: 100% hace que ocupe el espacio disponible hasta ese máximo.

Paso 3 / 5

Estilo de labels, inputs y estado de foco

Cada campo se apila verticalmente (label arriba, input abajo) usando flexbox en columna. Los inputs reciben un borde consistente que cambia de color cuando el usuario hace clic dentro con :focus.

estilos.css
.field {
  display: flex;
  flex-direction: column;
  margin-bottom: 18px;
  flex: 1;
}
.field label {
  font-size: .85rem;
  font-weight: 600;
  margin-bottom: 6px;
  color: #3d4160;
}
.field input, .field select {
  border: 1.5px solid #dcdaf0;
  border-radius: 8px;
  padding: 10px 12px;
  font-size: .95rem;
  outline: none;
  transition: border-color 0.15s ease;
}
.field input:focus, .field select:focus {
  border-color: #a78bfa;
}
¿Qué hace cada regla?
.field → flex-direction: columnApila el label sobre el input en vez de ponerlos en fila (que sería el comportamiento por defecto de flex).
outline: none + border transitionSe quita el contorno azul por defecto del navegador para reemplazarlo con un cambio de color de borde propio, animado suavemente.
:focus → border-colorSe activa automáticamente mientras el input está seleccionado (el cursor parpadeando dentro). Le da al usuario una señal visual clara de en qué campo está escribiendo.

Paso 4 / 5

Fila de dos campos y checkbox

Nombre y Correo van lado a lado usando flexbox con gap. El checkbox necesita su propio layout horizontal, distinto al de los demás campos.

estilos.css
.row {
  display: flex;
  gap: 12px;
}

.field.checkbox {
  flex-direction: row;
  align-items: center;
  gap: 8px;
}
.field.checkbox input { width: 16px; height: 16px; }
.field.checkbox label { margin: 0; font-weight: 400; }
¿Qué hace cada regla?
.row → display: flex + gapPone los dos .field hijos en fila. Como cada .field tiene flex: 1 (paso 3), ambos ocupan el mismo ancho automáticamente.
.field.checkbox → flex-direction: rowSobreescribe la regla general de .field (que apila en columna) solo para el checkbox, que necesita quedar al lado de su texto, no encima.
.checkbox input → width/height: 16pxFija un tamaño consistente para la casilla, que de otro modo variaría según el navegador.

Paso 5 / 5 · Reto final

Botón de envío y playground editable

El botón usa los mismos principios de estado que el input: apariencia base, :hover para retroalimentación al pasar el mouse, y transición suave entre ambos. Desde aquí puedes editar libremente todo el formulario.

estilos.css
.formulario button {
  width: 100%;
  background: #a78bfa;
  color: white;
  border: none;
  padding: 12px;
  border-radius: 8px;
  font-weight: 700;
  font-size: .95rem;
  cursor: pointer;
  transition: background 0.15s ease;
}
.formulario button:hover { background: #8f6ff0; }

/* pantallas angostas: la fila de nombre/correo se apila */
@media (max-width: 480px) {
  .row { flex-direction: column; gap: 0; }
}
¿Qué hace cada regla?
width: 100%El botón ocupa todo el ancho de la tarjeta, un patrón común en formularios para darle prioridad visual a la acción principal.
cursor: pointerCambia el ícono del mouse a una manito al pasar por encima, reforzando que el elemento es interactivo (por defecto los <button> ya lo hacen, pero es buena práctica declararlo).
:hover → backgroundOscurece ligeramente el color al pasar el mouse, dando retroalimentación antes incluso de hacer clic.
@media (max-width: 480px)En pantallas muy angostas (celulares), la fila de Nombre/Correo pasa de dos columnas a una sola, apilando los campos para que no queden demasiado angostos.
