Cómo está organizada esta guía

Primero se explican, en un lenguaje sencillo, los conceptos de JavaScript y de localStorage que vas a necesitar. Después se construye el HTML, luego el CSS y por último el JavaScript, dividido en segmentos pequeños: cada fragmento de código va seguido inmediatamente de su explicación, y nada se deja fuera ni se resume con puntos suspensivos. Entre paso y paso encontrarás un checkpoint visual: una imagen que muestra cómo debe verse la tienda en ese punto.

El código de esta guía está bloqueado para copiar y pegar a propósito. Transcríbelo a mano en tu propio editor: escribir cada línea te obliga a leerla con atención.
No hay ningún entorno para ejecutar código dentro de esta guía. Debes crear los archivos index.html, style.css y script.js en tu computador y abrirlos en tu navegador para probarlos.
Los "checkpoints" son imágenes (dibujadas en SVG) que muestran el aspecto y el contenido esperado de la tienda en un momento dado, no el código ni una demostración interactiva.
Proyecto

Carrito de compras para una tienda online

Vamos a construir una página con un catálogo de productos y un carrito lateral. Al agregar productos, cambiar cantidades o eliminarlos, el carrito se guarda automáticamente en el navegador con localStorage, así que sigue ahí aunque se recargue la página. Al finalizar la compra, se muestra una confirmación y el carrito se vacía por completo.

Conceptos que necesitas

localStorage.setItem() / getItem()

Es un espacio de almacenamiento que el navegador reserva para cada sitio web. setItem(clave, valor) guarda algo bajo un nombre; getItem(clave) lo recupera después, incluso si se cierra y se vuelve a abrir la página.

JSON.stringify() / JSON.parse()

localStorage solo puede guardar texto, nunca objetos ni arrays directamente. JSON.stringify(valor) convierte un array u objeto en texto; JSON.parse(texto) hace el proceso inverso.

array.find()

Recorre un array y devuelve el primer elemento que cumpla una condición, o undefined si ninguno la cumple. Lo usamos para buscar un producto por su id.

array.filter()

Devuelve un array nuevo con solo los elementos que cumplen una condición. Lo usamos para quitar un producto del carrito sin tener que buscar y borrar manualmente su posición.

array.reduce()

Recorre un array acumulando un solo valor final. Lo usamos para sumar el precio de todos los productos del carrito y obtener el total a pagar.

Delegación de eventos

Tanto el catálogo como el carrito escuchan los clics en su contenedor completo, no en cada botón individual, porque las tarjetas y las filas se crean y se destruyen constantemente.

number.toLocaleString()

Formatea un número según una configuración regional; con "es-CO", un precio como 250000 se muestra como 250.000, con puntos separando los miles.

Renderizar y guardar juntos

Cada vez que el carrito cambia, se vuelve a dibujar por completo y se guarda en localStorage en el mismo paso, para que la pantalla y el almacenamiento nunca queden desincronizados.

Paso 1: estructura HTML

La página tiene dos columnas: el catálogo de productos a la izquierda y el carrito a la derecha. Ninguna tarjeta de producto ni fila del carrito se escribe a mano: todo el contenido dinámico lo genera JavaScript dentro de estos contenedores vacíos.

El <div id="listaProductos"> empieza vacío y se llena con una tarjeta por producto. El <div id="itemsCarrito"> también empieza vacío, y se llena con una fila por cada producto agregado al carrito. El <span id="totalCarrito"> permite actualizar solo el número del total sin reescribir toda la frase. El <p id="mensajeCheckout"> está preparado para mostrar el resultado de la compra al final.

Paso 2: estilos CSS

El CSS organiza la página en dos columnas, le da apariencia de tarjeta a cada producto, y define cómo se ven las filas del carrito y los mensajes de éxito o error del checkout.

display: grid en .tienda con grid-template-columns: 1fr 340px crea dos columnas: el catálogo ocupa todo el espacio disponible, y el carrito tiene un ancho fijo de 340 píxeles. Dentro del catálogo, .listaProductos también es una cuadrícula, pero con columnas flexibles que se ajustan automáticamente al espacio disponible. Las clases .mensajeCheckout.exito y .mensajeCheckout.error son las que le dan color verde o rojo al mensaje final, según el resultado.

Paso 3: lógica en JavaScript

Esta es la parte más larga de la guía. La vamos a construir en 12 segmentos pequeños, cada uno explicado justo después de escribirlo, hasta llegar al checkout final.

Segmento 1: los productos y el estado del carrito

productos es un array fijo con los 4 artículos de la tienda; cada uno tiene un id único, un nombre, un precio y una categoria (que vamos a usar para dibujar un ícono distinto por producto). carrito es el estado real del carrito: un array que empieza vacío y que va a contener objetos como { id: 1, cantidad: 2 }, uno por cada producto distinto agregado. Está declarado con let porque más adelante lo vamos a reemplazar por completo varias veces (al vaciar el carrito o al cargar uno guardado).

Segmento 2: seleccionar los elementos del DOM

Guardamos en variables cada elemento del HTML que vamos a necesitar: los dos contenedores principales, el texto del total, los dos botones de acción y el párrafo del mensaje final.

Segmento 3: crear los íconos de cada producto

En vez de usar imágenes o emoticones, cada producto se representa con una figura simple dibujada en SVG, según el texto guardado en su propiedad categoria. Esta función recibe esa categoría y devuelve el código SVG correspondiente: un círculo azul, un cuadrado verde, un triángulo naranja o una estrella roja.

Segmento 4: pintar el catálogo de productos

renderProductos() vacía el contenedor del catálogo y recorre el array productos con forEach. Por cada producto crea una tarjeta completa: un <div> para el ícono (usando la función del segmento anterior), un <p> para el nombre, otro <p> para el precio ya formateado con toLocaleString("es-CO"), y un <button> que guarda el id del producto en dataset.id. El catálogo, a diferencia del carrito, no cambia mientras el usuario compra, así que esta función solo se llama una vez al cargar la página.

Segmento 5: guardar y cargar el carrito con localStorage

guardarCarrito() convierte el array carrito en texto con JSON.stringify y lo guarda en localStorage bajo la clave "carritoTienda". cargarCarrito() hace lo contrario: intenta leer esa clave con getItem, y si existe algo guardado (es decir, si no es null), lo convierte de vuelta a un array real con JSON.parse y lo asigna a carrito. Estas dos funciones son el corazón de la persistencia: sin ellas, el carrito se perdería cada vez que se recargue la página.

Segmento 6: calcular el total a pagar

calcularTotal() usa carrito.reduce(...) para recorrer todos los productos del carrito y acumular un solo número. El segundo argumento de reduce, el 0, es el valor inicial del acumulador. En cada vuelta, se busca el producto real correspondiente con find (porque el carrito solo guarda el id y la cantidad, no el precio), y se suma producto.precio * itemCarrito.cantidad al acumulado. Si por alguna razón el producto ya no existiera, se devuelve el acumulado sin cambios, evitando un error.

Segmento 7: pintar el carrito

renderCarrito() vacía el contenedor del carrito y, si está vacío, muestra el mensaje "Tu carrito está vacío." Si tiene productos, recorre carrito con forEach: por cada item busca el producto real con find, calcula su subtotal (precio por cantidad), y construye la fila completa de una sola vez con innerHTML y una cadena de texto, incluyendo los botones de sumar, restar y eliminar con el id del producto guardado en data-id. Al final de la función, siempre se actualiza el texto del total llamando a calcularTotal(), y se llama a guardarCarrito(): así, cada vez que se pinta el carrito, también queda guardado en localStorage, sin que tengamos que acordarnos de hacerlo por separado en cada lugar donde el carrito cambia.

Checkpoint visual 2 de 3

Con dos productos agregados: cada fila muestra sus controles de cantidad, su subtotal y su botón de eliminar, y el total ya suma $370.000. Si en este punto recargas la página, gracias a localStorage el carrito aparece exactamente igual.

Segmento 8: agregar productos al carrito

agregarAlCarrito(idProducto) primero busca, con find, si ese producto ya está en el carrito. Si ya existe, simplemente le suma 1 a su cantidad; si no existe todavía, agrega un objeto nuevo al array con push, empezando en cantidad 1. Al final, llama a renderCarrito() para que el cambio se refleje en pantalla (y de paso se guarde en localStorage, como vimos en el segmento anterior).

El addEventListener("click") está puesto en el contenedor completo del catálogo (delegación de eventos), no en cada botón: así funciona sin importar cuántos productos tenga el catálogo. Con evento.target.closest(".btnAgregar") se identifica si el clic fue realmente sobre un botón de "Agregar al carrito"; si fue así, se lee el id guardado en dataset.id (convertido a número, porque los atributos siempre llegan como texto) y se llama a agregarAlCarrito con ese valor.

Segmento 9: cambiar cantidades y eliminar productos

Este addEventListener("click") está en el contenedor del carrito, también con delegación de eventos, porque las filas se destruyen y se vuelven a crear cada vez que se llama a renderCarrito(). Tras encontrar el botón exacto que se presionó y el item del carrito al que pertenece, se revisa qué clase tiene ese botón: si es btnSumar, se aumenta la cantidad en 1; si es btnRestar, se disminuye en 1, y si llega a 0 o menos, se elimina ese producto del carrito por completo con filter (que crea un nuevo array sin ese id); si es btnEliminarItem, se elimina directamente sin importar la cantidad. En los tres casos, se termina llamando a renderCarrito() para reflejar el cambio.

Segmento 10: vaciar el carrito manualmente

El botón "Vaciar carrito" simplemente reemplaza carrito por un array vacío, limpia cualquier mensaje anterior del checkout y vuelve a pintar el carrito (que ahora mostrará el mensaje de carrito vacío y guardará ese estado vacío en localStorage).

Segmento 11: el checkout que limpia el carrito

Al hacer clic en "Finalizar compra", primero se comprueba si el carrito está vacío; si lo está, se muestra un mensaje de error (con la clase "error", que el CSS pinta de rojo) y no se continúa. Si hay productos, se calcula el totalPagado con la función calcularTotal() del segmento 6, y se muestra un mensaje de éxito (con la clase "exito", en verde) confirmando la compra con el total ya formateado. Justo después viene la parte más importante de este paso: carrito = [] vacía el carrito por completo, y renderCarrito() refleja ese vaciado en pantalla y en localStorage, dejando la tienda lista para una compra nueva.

Segmento 12: iniciar la tienda al cargar la página

Estas tres líneas finales son las que realmente ponen en marcha todo lo anterior, en un orden preciso: primero cargarCarrito() intenta recuperar un carrito guardado de una visita anterior; luego renderProductos() dibuja el catálogo (que siempre es el mismo); y por último renderCarrito() dibuja el carrito ya sea vacío o con lo que se haya recuperado de localStorage, y lo vuelve a guardar para mantener todo sincronizado desde el primer instante.

Para seguir practicando

Una vez que la tienda funcione, prueba agregar un campo de cantidad disponible por producto (para no dejar agregar más unidades de las que hay en stock), un descuento por cantidad, o una lista de "compras anteriores" guardada también en localStorage bajo otra clave distinta a "carritoTienda".
